## 代码库模式
- vphone-cli 使用 @MainActor 标注所有 VM/UI 类，nonisolated 委托方法通过 MainActor.run {} 跳回主 Actor
- 新增 Swift 文件需在 Package.swift 的 targets 中的 sources 目录内，SwiftPM 会自动发现
- 现有 Makefile 通过 cd $(VM_DIR) && vphone-cli ... 启动，vphone-cli 运行时 CWD 即为 VM 目录
- 使用 make build 而非 swift build（需要 codesign 签名才能运行）
- VPhoneControl 使用 length-prefixed JSON（uint32 大端 + UTF-8 JSON）作为 vsock 协议
